One original fortune-cookie line for a software developer, written to `/output/entry.txt` by `main.ts`. The line is about legacy code: the code you curse today was once someone's clever idea, written at 2 a.m. with the best of intentions — a quiet reminder that today's clever fix is tomorrow's legacy.

## Run

```sh
node main.ts
```

This writes the fortune (104 characters, one line, no trailing newline) to `${OUTPUT_DIR:-/output}/entry.txt`. Set `OUTPUT_DIR` to choose another output directory.
